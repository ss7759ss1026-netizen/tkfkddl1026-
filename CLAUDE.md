### 25. SIGNATURE MEMORY SYSTEM

Each song should have ONE primary memorable Instrument Memory Hook.
Examples: 3-note guitar harmonic motif, descending 4-note piano answer,

pickup before chorus, organ call-and-response, vibraphone 3-note answer,
clav rhythmic cell.

SIGNATURE ≠ decoration. SIGNATURE = MEMORY. Avoid multiple competing signatures.

### 26. ENTRY / EXIT DNA

Use: ENTRY, EXIT, RE-ENTRY, PLAYING CHANGE, REGISTER CHANGE, SILENCE,
RHYTHMIC CHANGE.

Do not grow every arrangement only by adding layers.

ENTRY REASON: A EMOTIONAL / B RHYTHMIC / C HOOK / D CONTRAST

EXIT matters as much as ENTRY.

### 27. SECTION DENSITY (reference only, not a rigid preset)

Intro 1–2, Verse 1 2–3, Pre 2–4, Chorus 3–5, Tag 2–4, Verse 2 3–4,
Pre 2 2–4, Chorus 2 3–5, Break 1–3, Bridge 1–3, Final Chorus 3–5,
Final Tag 2–4, Outro 1–2.

### 28. STRUCTURE STANDARD

DEFAULT:

```
Short Intro → Verse 1 → Pre → Chorus → Tag → Verse 2 → Pre → Chorus
→ 8-Bar Instrumental Break → Bridge (when justified) → Final Chorus
→ Final Tag → Outro
```

**INTRO:** short, signature-first / cold vocal / rhythmic pickup /
single-instrument hook allowed. Avoid long cinematic intro, random
humming, generic wordless opening. Early lyric entry preferred.
Approx. 2.2–2.6 sec is a reference, not a fixed preset.

**VERSE 1:** Groove Engine + Anchor. Leave space.

**PRE:** Growth may come from subtraction.

**CHORUS:** Movement before Width. Everything-On prohibited as default.

**VERSE 2:** Do not copy Verse 1 arrangement.

**CHORUS 2:** One meaningful evolution is enough.

### 29. 8-BAR BREAK

8 BARS, NO VOCAL. Break = INSTRUMENT IDENTITY SHOWCASE.

Example: Bars 1–2 Bass + minimal drums / Bars 3–4 Signature enters /
Bars 5–6 Signature ↔ Bass / Bars 7–8 Simplify / transition

Do not reuse identical Break behavior across songs.

### 30. BRIDGE / FINAL / OUTRO

**BRIDGE:** Consider SUBTRACTION first. Create a new emotional viewpoint.

**FINAL CHORUS:** Never default to EVERYTHING ON. Choose only necessary
2–3: Register ↑, Rhythmic Activity ↑, Vocal Harmony ↑, Bass Movement ↑,
Drum Openness ↑, Signature Return.

**OUTRO:** Do not introduce new instruments. Leave SIGNATURE or HUMAN
TRUTH TRACE.

### 31. SIGNATURE RE-ENTRY

Do not play the signature continuously. Possible: INTRO → disappear →
CHORUS → disappear → BREAK → FINAL TAG / OUTRO. RE-ENTRY = MEMORY.
