01_Image_Generation

SAMDADORA 이미지 생성 워크플로우

이 폴더는 SAMDADORA AI 음악 및 YouTube 플레이리스트에 사용할 이미지 생성 워크플로우를 보관합니다.

원본 JSON 파일

Qwen_image_2.1_00001.json

주요 용도

- YouTube 플레이리스트 배경 이미지 제작
- AI 음악 앨범 커버 이미지 제작
- 제주 바다·카페·도시 풍경 이미지 생성
- 영상 제작에 사용할 원본 이미지 준비

사용 방법

1. ComfyUI를 실행합니다.
2. JSON 워크플로우를 불러옵니다.
3. 필요한 모델과 노드를 확인합니다.
4. 이미지 생성 프롬프트를 입력합니다.
5. 결과를 검수한 후 저장합니다.

원본 보존 규칙

- JSON 원본은 수정하지 않습니다.
- 새로운 설정은 별도 버전으로 저장합니다.
- ComfyUI 실행 검증 전에는 상태를 UNKNOWN으로 표시합니다.
