### 결론 — WORKING HYPOTHESIS (확정 규칙 아님)

- 잘 된 제목은 **듣는 사람이 실제로 내뱉을 반응 + 기분이 좋아진다는 약속**이다.
- **가사처럼 쓴 시적인 제목은 일관되게 졌다.** 이야기는 가사에, 제목은 듣는 사람의 말로.
- 다섯 채널 모두 **일하는 장면의 반응**을 쓴 제목은 없었다 → SAMDADORA의 빈자리.
- 영상 길이는 2시간 이상이 약간 앞섰지만(1.0~1.1x vs 0.7~0.8x) 채널별 길이 습관 때문에 판단 보류.
- 제목 공식 분류기는 한글 제목을 거의 판정하지 못했다(1개만 The Question).
- 재검증: 다음 달 같은 다섯 채널을 다시 찍어 비교한다.

## 2. 본편 제목 · 썸네일 (`/yt-package`)

```
Playlist | 틀자마자 오늘 할 일 다 끝낼 것 같아 🎧 기분 좋은 작업용 그루브 팝
```

```
썸네일 문구: Work Groove
```

- `title.py` 80/100 — 50자(데스크톱 60자 안). 모바일 피드는 "…끝낼 것 같아 🎧 기분 좋은"까지 보임
  (한글은 폭이 넓어 더 앞에서 잘릴 수 있음, 업로드 후 휴대폰 확인).
- 숫자 없음 감점은 장르 관행상 유지. 넣는다면 실제 길이와 맞는 `| 2시간`만.
- **썸네일 장면:** 오후 늦은 햇살이 드는 책상, 반쯤 열린 노트북, 커피잔, 이어폰. 인물은 화면 보며
  살짝 웃는 옆모습. 오렌지·베이지 톤. `Work Groove`를 가운데 큰 세리프체로, 배경은 어둡거나 흐리게.
- **피할 것:** 실제 연예인 얼굴, 다른 채널 썸네일과 닮은 구도, 문구 3단어 이상.

## 4. 쇼츠 3편 (`/yt-shorts`)

### 구간 고르는 규칙 (음악용)

- **Pre-chorus 첫 박 → Chorus → Tag 끝**, 110 BPM 기준 약 38초
  (1박 ≈ 0.55초, 1마디 ≈ 2.2초, 후렴 8마디 ≈ 17초).
- 세 편은 각각 **다른 곡**에서 자른다.
- 화면 문구와 가사는 다른 말을 한다.
- 세로 9:16 화면 녹화, 문구는 화면 위쪽 1/3 (아래·오른쪽은 쇼츠 버튼이 가림).
- 본편을 각 쇼츠의 "관련 동영상"으로 연결, 본편 고정 댓글에 쇼츠 링크.
- 올리는 순서: 본편 → 1번 → 2번 → 3번.

### 세 편 한눈에

| 쇼츠 | 형식 | 이어받는 할 일 | 후렴 첫 박의 순간 | 훅 점수* | 곡 / 구간 |
|---|---|---|---|---|---|
| 1 | POV형 | 4줄 전체 | 체크가 쌓이기 시작 | 62 WORKABLE | PENDING |
| 2 | 약속형 | 미뤄둔 엑셀 수식 고치기 | 파일이 폴더로 쏙 | 64 WORKABLE | PENDING |
| 3 | 실험형 | 팀장님 피드백 반영 | 흐림이 확 걷힘 | 54 WEAK | PENDING |

\* `hookscore.py`, 영어로 옮긴 문장으로 채점 (한글 채점 불가 우회).

### 촬영 공통 체크리스트

- [ ] 방해 금지 모드
- [ ] 화면 밝기 최대, 글자 크기 한 단계 크게
- [ ] 실제 업무 내용·이름·회사명 금지 (전부 연출용)
- [ ] 소리 없이 녹화, 음악은 편집에서 원곡 파일로
- [ ] 편집에서 상단바 잘라내기
- [ ] 핵심 순간을 후렴 첫 박 마커에 맞추기
- [ ] 마지막 0.3초 페이드아웃 (루프)
- [ ] 실제 쇼츠 화면으로 문구 가림 확인

세 장면 모두 같은 날 휴대폰 하나로 약 30분이면 녹화 가능.

### 쇼츠 1 — POV형 (메모 앱 체크리스트)

```
☐ 슬랙 안 읽음 47개
☐ 미뤄둔 엑셀 수식 고치기
☐ 팀장님 피드백 반영
☐ 노트북 덮고 퇴근 🎧
```

```
0~2초      POV: 퇴근 30분 전, 남은 일 4개
34~38초    남은 일 0개. 퇴근 ✔
38~39초    내일도 4개 남으면?
```

```
고정 댓글: 여러분의 퇴근 전 남은 일 4개는 뭐예요?
```

| 구간 | 시간 | 화면 |
|---|---|---|
| Pre-chorus | 0~17초 | 체크 안 된 4줄 |
| Chorus | 17~34초 | 2마디(≈4.4초)마다 위에서부터 하나씩 ✔ |
| Tag | 34~38초 | 4줄 모두 체크 |
| 루프 | 38~39초 | 같은 화면 |

- 체크 사이 3~4초씩 두고 천천히 2~3번 녹화 → 편집에서 마디 첫 박에 맞춰 자름.

### 쇼츠 2 — 약속형 (파일 앱)

```
파일:  수식수정_3일째.xlsx  (빈 파일)
폴더:  완료
```

```
0~2초      3일째 미룬 일 1개, 이 노래 한 곡이면 끝나요
34~38초    끝. 생각보다 별거 아니었죠?
38~39초    다음 곡은 뭘 끝낼래요?
```

```
고정 댓글: 여러분이 3일째 미루고 있는 일 하나는 뭐예요?
```

| 구간 | 시간 | 화면 |
|---|---|---|
| Pre-chorus | 0~15초 | 파일 하나와 `완료` 폴더 |
| 후렴 직전 | 15~17초 | 파일을 길게 눌러 들어 올린 상태 |
| Chorus 첫 박 | 17초 | 파일이 `완료` 폴더로 쏙 |
| Chorus~Tag | 17~38초 | `완료` 폴더 안 |
| 루프 | 38~39초 | 같은 화면 |

- 아이콘(격자) 보기로. 끌어다 놓기가 안 되면 "이동" 메뉴 장면 + 편집에서 순간만 맞춤.

### 쇼츠 3 — 실험형 (문서 스크롤 + 흐림 효과)

```
문서:  피드백 반영본_v3  (가짜 회의록 20~30줄 + 형광펜 몇 군데)
```

```
0~2초      오후 3시, 집중 끊겼다면 이 노래 30초만
34~38초    돌아왔다.
38~39초    다시 3시가 오면 ↺
```

```
고정 댓글: 여러분은 몇 시에 집중이 제일 많이 끊겨요?
```

| 구간 | 시간 | 흐림 |
|---|---|---|
| Pre-chorus | 0~16.5초 | 강하게 (글자 안 읽힘) |
| 후렴 직전 | 16.5~17초 | 강하게 유지 |
| Chorus 첫 박 | 17초 | 0.5초 안에 0 |
| Chorus~Tag | 17~38초 | 없음 |
| 루프 | 38~39초 | 다시 약하게 |

- 흐림 키프레임: 0초 강 · 16.5초 강 · 17초 0 · 39초 약.
  키프레임이 어려우면 17초에서 클립을 잘라 앞쪽에만 흐림.
- 문구는 "이 후렴 30초만"에서 수정함 — 후렴 자체는 ≈17초라 실제와 맞는 "이 노래 30초만"으로.
